# Project Charter
# Practice Software Testing End-to-End QA Project

# 1. Project Overview
This project focuses on comprehensive quality assurance testing of the Practice Software Testing (Toolshop) e-commerce web application.

**Application URL:** https://practicesoftwaretesting.com/

The project will demonstrate manual testing, UI automation, API testing, performance testing, accessibility testing, defect management, and CI/CD practices.

# 2. Project Objectives
- Analyse and document functional requirements.
- Design and execute manual test cases.
- Identify, reproduce, and report defects.
- Develop Playwright automation using JavaScript.
- Validate API functionality using Postman and Playwright.
- Perform responsive and cross-browser testing.
- Conduct performance testing in a controlled environment.
- Evaluate accessibility against WCAG guidelines.
- Integrate automated tests with GitHub Actions.
-  Produce professional QA test reports.

# 3. Testing Scope

# Functional Testing
- User registration and authentication
- Product search and filtering
- Product categories and details
- Shopping cart functionality
- Checkout workflow, where supported
- User account management

# Non Functional Testing
- UI and responsive testing
- Cross-browser compatibility
- Accessibility testing
- Performance testing
- Basic security validation

# Additional Testing
- API testing
- Database testing, where accessible
- Regression testing
- Automation testing

# 6. Success Criteria
- Requirements have documented test coverage.
- Test cases have recorded execution results.
- Confirmed defects include reproducible steps.
- Automated tests run consistently.
- API and performance results are evaluated against documented expectations.
- CI/CD execution results and relevant artifacts are available.
- GitHub repository clearly demonstrates the complete QA process.

# 7. Risks and Limitations
- Public demo environments may change or become temporarily unavailable.
- Some functionality may not be accessible without suitable test accounts.
- Database access may require a local installation.
- Load and stress testing must be performed only in an authorised, controlled environment.
- Security testing will be limited to safe, authorised checks.
- Test scope and expected results will be refined after application exploration.

# 8. Expected Outcome
A structured, documented, and reproducible end-to-end QA portfolio project demonstrating practical software testing and quality engineering skills.
