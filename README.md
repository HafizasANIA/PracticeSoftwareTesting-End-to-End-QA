

#Practice Software Testing — End-to-End QA Project

# Project Overview
A comprehensive Software Quality Assurance portfolio project for the Practice Software Testing (Toolshop) e-commerce application.

# Application Under Test
https://practicesoftwaretesting.com/

# Testing Scope
- Manual Functional Testing
- UI and Responsive Testing
- Cross-Browser Testing
- Playwright Automation with JavaScript
- API Testing with Postman and Playwright
- Database Testing (where accessible)
- Performance Testing using k6 in a controlled environment
- Accessibility Testing
- Defect Management using Jira
- CI/CD using GitHub Actions
